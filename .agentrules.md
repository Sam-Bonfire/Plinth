# PlinthOS Agent Rules & Invariants

This file provides non-negotiable operational instructions for AI agents working in this repository.

---

## 1. Branching & Pull Requests
- **Base Branch**: Always branch off and target `dev`. Direct pushes to `main` and `dev` are strictly forbidden.
- **Branch Naming**: Follow `<type>/<short-kebab-description>` (e.g. `feat/kds-ui`, `fix/order-calc`).
- **Conventional Commits**: Format commit messages as `<type>(<scope>): <summary>` with a detailed body and `For: <task-id>` in the commit footer.

---

## 2. Task Management & Notion Sync
- **Status Invariant**: Tasks MUST remain `In Progress` while PRs are open.
- **Never Complete Early**: Do NOT update Notion tasks to `Completed` until the PR is officially merged into `dev`.
- **Local PR Batching**: Group logically related granular domain tasks into unified local PRs rather than opening micro-PRs for single enums or files.

---

## 3. Environment & Task Execution
- **Task Runner Parity**: Always use `mise run <task>` (e.g. `mise run lint`, `mise run test`, `mise run ui:capture`) instead of arbitrary raw terminal commands.
- **Zero Unsafe Code**: All Rust code MUST include `#![forbid(unsafe_code)]` or `#![deny(unsafe_code)]`.
- **Financial Precision**: All financial and tax math MUST use `rust_decimal::Decimal`. IEEE-754 floats are forbidden.
- **Domain First**: UI mockups are for visual flow only; build real, scalable domain models first and derive mocks/tests from them.
